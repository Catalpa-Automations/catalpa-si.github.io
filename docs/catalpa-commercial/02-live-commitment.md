## 5. Change requests = new quote

Anything outside the signed Scope Boundary (new integrations, extra branches, custom reports, second brand, ERP links, native apps, etc.) is a **change request**.

1. Client describes the change.  
2. Catalpa sends a **short written quote** (GHS + timeline).  
3. Work starts **only after** Client accepts the quote and pays any agreed deposit for that change.  

No silent extras. No “we added it, please pay.”
