# Website Sprint — Delivery Checklist (Ghana SME)

**Positioning:** This sprint sits **on** Google Business Profile + WhatsApp + Paystack/MoMo. You are not building a Maps, Search, or chat platform. The site is a mobile landing that sends people to tools they already use.

Use for every client. Tick before collecting the final 50%.

---

## Day 0 — Close & intake

- [ ] 50% deposit received (MoMo / Paystack) — reference saved
- [ ] Signed or WhatsApp-confirmed proposal (scope, pages, timeline)
- [ ] Intake form complete: business name, category, address, hours, WA number (`233…`), logo/photos, colours if any
- [ ] Confirm Google Business Profile status: **claimed / unclaimed / suspended**
- [ ] Confirm WhatsApp Business vs personal — prefer Business app for catalog later
- [ ] Pick template: restaurant · salon/barber · pharmacy/clinic (or hybrid)
- [ ] Staging subdomain reserved (e.g. `client.yourdomain.com` or Netlify draft)

---

## Days 1–2 — GBP + homepage mock (pitch proof)

- [ ] Claim or request access to Google Business Profile (client owns the listing)
- [ ] Primary category set correctly (Ghana-relevant: Restaurant, Beauty salon, Pharmacy, etc.)
- [ ] Address + GPS pin correct (estate / landmark note in description if needed)
- [ ] Hours match real shop hours (include public holidays note if they close)
- [ ] Phone = WhatsApp-reachable number
- [ ] Website field = staging URL (update to live at handover)
- [ ] Cover + logo uploaded (min 720px logo; cover 1024×576+)
- [ ] 5–10 real photos (storefront, interior, product/service) — no stock clutter
- [ ] Homepage mock customized with **their** name, WA link, 3 menu/service items
- [ ] Send mock on WhatsApp: “Here’s your homepage draft — reply with changes”

---

## Days 3–5 — Build site

- [ ] Copy template → replace brand, copy, prices (GHS), hours, Maps link
- [ ] WhatsApp CTAs: `https://wa.me/233XXXXXXXXX?text=…` on hero + sticky mobile bar
- [ ] Pre-filled WA messages for order / book / prescription (niche-specific)
- [ ] MoMo/Paystack button: placeholder replaced with **real** payment page or link
- [ ] Mobile check: 375px width — CTA thumb-reachable, no horizontal scroll
- [ ] Meta title + description (Ghana city + niche keywords)
- [ ] Favicon + Open Graph image (optional but sharp for WA status shares)
- [ ] Footer: address, WA, Maps link, “Pay with MoMo”
- [ ] Hosting live (Netlify / Cloudflare Pages / Vercel) — HTTPS on
- [ ] Custom domain if in scope (DNS screenshot for client)

---

## Days 5–7 — GBP polish + handover

- [ ] GBP website URL → **live** domain
- [ ] GBP products/services or menu filled (where category supports)
- [ ] Q&A seeded (2–3 common questions answered as business)
- [ ] Messaging / chat link points to WhatsApp if GBP chat unused
- [ ] Review request: short WA script for client to send after happy sales
- [ ] Train client (15–20 min call or WA voice note): edit hours, reply to reviews, share site link
- [ ] Handover pack: live URL, GBP link, login ownership note, Paystack link, this checklist PDF
- [ ] Final 50% collected
- [ ] Ask for WhatsApp testimonial + permission to show before/after in portfolio
- [ ] **Upsell logged:** WA CRM setup and/or ReceiptMoMo (see README)

---

## Out of scope (say no / quote separately)

- Meta / Google / OpenAI platform features or “beat Maps/Search”
- Full e-commerce with inventory (upsell Chat Catalog bot)
- Click-to-WhatsApp ads management (separate retainer)
- BookMe calendar automation (upsell after salon/clinic sprint)
- Holding customer funds or screenshot-as-proof payments

---

## Done definition

Client can: (1) open site on phone, (2) tap WhatsApp and get a prefilled message, (3) pay via MoMo/Paystack link, (4) find the business on Google Maps with matching hours and the site URL.
