# Google Business Profile — Ghana Optimization Checklist

**Role of GBP in this sprint:** The listing is the discovery layer (Maps / Search). Your website is the conversion layer (WhatsApp + MoMo). Do not try to “replace Google” — make the profile accurate and point it at the site.

Owner should be the **client’s Google account**. You help; they keep ownership.

---

## 1. Claim & ownership

- [ ] Search the business on Google Maps before creating a duplicate
- [ ] Claim via postcard / phone / email as offered — Accra/Kumasi addresses often verify by phone
- [ ] Add yourself as **Manager** only; client remains Owner
- [ ] Reject / merge duplicate listings if the shop already appears twice
- [ ] Check for suspension (edited too aggressively, wrong category, fake address) — appeal with proof photos if needed

---

## 2. Core NAP (Name · Address · Phone)

- [ ] **Name** matches storefront sign + WhatsApp Business display name (no keyword stuffing: avoid “Best Pharmacy Accra Cheap Meds”)
- [ ] **Address** uses Ghana-recognizable format: street / house no. / area / city (e.g. “Near Madina Station, Madina, Accra”)
- [ ] Drop a precise **pin** — estates and compounds confuse Maps; walk the pin with the owner
- [ ] **Primary phone** = the WhatsApp number staff actually answer (country code +233)
- [ ] Secondary phone optional (landline / second shop line)
- [ ] Website = live sprint URL (HTTPS)

---

## 3. Categories (Ghana-relevant examples)

Pick **one primary**, then secondary only if true:

| Niche | Primary (examples) | Secondary ideas |
|---|---|---|
| Restaurant / chop bar | Restaurant, African restaurant, Fast food restaurant | Caterer, Juice shop |
| Salon / barber | Beauty salon, Hair salon, Barber shop | Nail salon, Spa |
| Pharmacy / clinic | Pharmacy, Drug store, Medical clinic | Doctor, Health consultant |

- [ ] Primary category matches what customers search
- [ ] Remove irrelevant categories that trigger spam flags

---

## 4. Hours & special hours

- [ ] Regular hours match the door and the website footer
- [ ] Add **special hours** for Ghana public holidays the shop closes (Independence Day, May Day, Christmas, Eid if applicable)
- [ ] Mark “Open 24 hours” only if truly true (some pharmacies)
- [ ] Consistent with WhatsApp “away” / auto-reply times

---

## 5. Description & attributes

- [ ] Description ≤750 chars: what you sell, area served, WhatsApp order/book line, MoMo accepted
- [ ] Write in clear English (or English + Twi/Ga greeting — keep searchable terms in English)
- [ ] Attributes: Wi-Fi, delivery, women-owned, wheelchair access — only if accurate
- [ ] Service area set if you deliver (Tema communities, East Legon, etc.) without faking a huge radius

---

## 6. Photos & media (trust in Ghana street commerce)

- [ ] Logo (square) + cover (wide)
- [ ] Storefront with readable signage (critical for “are you open?” trust)
- [ ] Interior / waiting area
- [ ] 5+ product or service shots (plates, fades, shelves — real, recent)
- [ ] Team optional; avoid borrowed internet images
- [ ] Refresh cover every 3–6 months

---

## 7. Products, services, menu

- [ ] Restaurant: add menu items with GHS prices where possible
- [ ] Salon: services with from-prices
- [ ] Pharmacy: avoid uploading controlled-drug catalogs; keep to OTC categories / services
- [ ] Link “order / book” CTAs to WhatsApp (site does the heavy CTA)

---

## 8. Messaging, booking, WhatsApp

- [ ] If using GBP messaging, set expected reply time — or turn off and push WhatsApp on the site
- [ ] Booking links: use your site `#` book section or BookMe later — not a fake calendar
- [ ] Q&A: seed 2–3 answers (“Do you take MoMo?”, “Are you open Sundays?”, “Do you need a prescription?”)

---

## 9. Reviews (ethical)

- [ ] Enable reviews
- [ ] After a good sale, client sends a short WA ask: “Please Google ‘[Business]’ and leave a star rating — link: [GBP short link]”
- [ ] Reply to every review within 48h (thank + invite WhatsApp for issues)
- [ ] Never buy fake reviews — Maps spam detection + brand risk

---

## 10. Consistency check (before handover)

- [ ] Name / phone / hours match **website** and **WhatsApp Business** profile
- [ ] Website field opens the sprint page on mobile
- [ ] Pin opens correct landmark
- [ ] Client can open Business Profile app / browser and edit hours alone

---

## Common Ghana failure modes

| Issue | Fix |
|---|---|
| Listing on wrong street / old shop | Re-pin with owner present; upload new storefront photo dated |
| Personal Gmail of ex-staff is Owner | Transfer ownership before sprint ends |
| Keyword-stuffed name | Revert to legal / signage name |
| Phone not on WhatsApp | Change to the line that gets answered |
| Website still Facebook page | Point to sprint URL; keep FB as social profile link |
